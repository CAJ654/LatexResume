# Resume
A digital Resume created using Overleaf and the LaTeX language

## GitHub Pages Deployment
This repository is configured to deploy to GitHub Pages using the `main` branch.

- `index.html` serves as the landing page.
- `main.pdf` is published alongside it.
- `.github/workflows/deploy.yml` builds and deploys to Pages on pushes to `main`.

To publish, push to `main` and enable GitHub Pages if needed in repository settings.
